# 第一章 操作系统概述

## 1.2 什么是操作系统

### 定义
- 管理硬件资源、控制程序运行、改善人机界面、为应用软件提供支持的系统软件
- 对下管理硬件，对上构筑应用生态

### 硬件角度
- 管理硬件：统一管理不同功能的硬件资源
- 硬件抽象：将硬件抽象为应用易用的资源

### 应用角度
- 服务应用
  - 提供计算资源抽象
  - 提供线程间同步
  - 提供进程间通信
- 管理应用
  - 生命周期管理
  - 计算资源分配
  - 安全与隔离
- 目标冲突
  - 服务目标：单应用运行效率最大化
  - 管理目标：系统整体资源利用率最大化

### 核心功能
- 资源转化：有限、离散硬件资源 → 无限、连续可用资源

### 软件角度
- 硬件资源虚拟化：底层硬件抽象封装，向上提供统一接口
- 管理功能可编程：提供可编程系统管理能力

### 结构角度
- 操作系统内核：核心资源管理和调度
- 系统框架：应用运行基础环境
- 整体 = 内核 + 框架

## 1.3 操作系统简史

### 1.3.1 批处理操作系统：GM-NAA I/O
- 1956年，IBM 704
- 输入/输出自动化，成批处理
- 世界上第一个实际使用的操作系统

### 1.3.2 通用操作系统：OS/360
- 1964年，IBM System/360
- 首次软硬件分离，通用操作系统时代
- 定义ISA，软硬件解耦
- 阿姆达尔定律（Amdahl）
- 《人月神话》，软件工程学科开创

### 1.3.3 分时与多任务：Multics → UNIX → Linux
- **Multics**（1964）：分时、文件系统、动态链接
- **UNIX**（1969）：shell、管道，1973年C语言重写
- **Linux**（1991）：开源，基于MINIX

### 1.3.4 图形化人机交互：Xerox Alto → macOS → Windows
- **Xerox Alto**（1973）：首个图形化OS，桌面、鼠标
- **macOS**：1983 Apple Lisa → Macintosh
- **Windows**：1985 Windows 1.0

### 1.3.5 移动互联网时代：iOS → Android
- **iOS**（2007）：多点触控，基于macOS内核（Mach + BSD），Cocoa Touch
- **Android**（2008）：基于Linux内核，开源，OHA联盟

## 1.4 操作系统接口

- **系统调用接口**：应用程序通过内核接口申请服务
- **POSIX接口**
  - Portable Operating System Interface for uniX
  - 继承UNIX API，IEEE提出
  - 通过C语言库（libc）在用户空间实现
  - 优点
    - 应用调用libc即可调用OS功能
    - 支持类UNIX系统可移植性
    - 新OS可移植libc以支持现有应用生态
- **领域应用接口**：在POSIX或系统调用基础上，面向不同领域封装
